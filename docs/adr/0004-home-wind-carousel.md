# ADR 0004 · 首页四旅程风叶轮播

- **Status**: Proposed（Simon 2026-09-15 已批准交互方向并授权施工，待正式架构评审）
- **Date**: 2026-09-15

## Context

“全部旅程”列表能管理不断增长的历史记录，但不适合首页高频切换。用户希望当前与近期旅程像风叶一样横向滑动，并让背景气氛随旅程连续变化；同时明确旅程不应成为工作排期，开放旅程数量需要温和上限。

## Decision

1. 首页只把正在进行与未来旅程放入横向吸附轮播，正在进行优先，未来旅程按出发日期排序；最多四个。历史旅程继续保存在“全部旅程”分组中，不占开放额度。
2. 卡片以露出下一张的方式提示横滑。滚动只动画 `transform` 与 `opacity`：当前卡回正，左右卡轻微旋转、下沉和缩放；系统减弱动态时取消这些形变。
3. `packages/ui` 统一维护四组明暗旅程色板。轮播输出归一化进度，首页据此连续插值背景；选中旅程同时驱动倒计时、清单进度和最近打开记录。
4. 整卡点击只负责选择，选中卡显示独立“进入旅程”按钮，避免卡片吸附动画与导航误触。点击侧卡时先完成程序滚动，再提交选中旅程及关联数据，防止父子状态同步取消滚动动画；减弱动态时直接提交。达到四个开放旅程时阻止继续创建或把历史旅程编辑为开放状态，并显示“旅程不是排期，生活不用赶集”。
5. “全部旅程”继续作为完整管理入口，保证超过四条历史数据仍可查找和进入。

## Consequences

首页保持聚焦和轻量，开放旅程数量不会无限扩张；历史数据仍完整可达。卡片顺序决定色板顺序，同一旅程在前方旅程结束后可能换色，这是当前无持久化主题字段的取舍。以后若需要用户自选封面主题，应新增独立契约评审，不能把展示色直接写进现有冻结实体。
