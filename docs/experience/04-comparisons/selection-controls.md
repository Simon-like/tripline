# 对比报告 · 选择控件形式（B 类）

> 2026-09-17。项目内全部"选项选择"目前只有一种形态——变色 chip/胶囊，无一处有动效反馈。本报告对比可选形态并给出分场景选型。

## 现状 vs 候选形态

| 形态 | 反馈强度 | 适用场景 | RN 成本 | 项目内先例 |
|---|---|---|---|---|
| 变色 chip（现状） | 弱：仅底色变化，≤150ms 响应达标但"无感" | — | 已有 | 记账分类、手账标签、清单分类、Day 切换 |
| Q 弹 chip（选中 scale 1→1.06→1 + 底色 + haptic） | 中：M3 Expressive 标准语言 | ≤8 个短选项的单/多选（分类、标签） | 极低：DatePickerSheet 的 BounceCapsule 已实现，抽出复用 | DatePickerSheet 选中胶囊（全项目手感标杆） |
| 卡片选择器（图标 + 标题 + 描述，选中描边 + 勾选角标） | 强：重要决策的仪式感 | 2–5 个需解释的重要选择（主题、旅程模板） | 低 | settings.tsx 主题三卡（已有雏形，缺动效） |
| 底部动作列表（BottomSheet 内列表 + 图标 + 说明文字） | 中：上下文完整 | 临时决策、选项随场景变化（导入来源、分享渠道、删除确认升级） | 低：BottomSheet 现成 | ShareSheet/ImportSheet（目前无图标） |
| 分段控件（segmented） | 中：即时生效语义 | 切换视图（账本"占比/趋势"切换、手账"全部/有图"筛选） | 低 | 无（TabBar 指示器机制可复用） |
| 滚筒选择器（惯性吸附 + 居中指示线） | 强：iOS 原生心智 | 有序数值（时间、预算档位） | 中：Reanimated scroll + snap 自绘 | 无 |

## 分场景选型建议

| 场景 | 现状 | 建议形态 | 理由 |
|---|---|---|---|
| 记账分类（6 项） | 变色 chip | Q 弹 chip + 图标 | 高频操作，值得 150ms 内可感知反馈；图标解决"六分类靠猜颜色" |
| 手账标签（多选） | 变色 chip | Q 弹 chip | 同上，多选不冲突 |
| 手账心情 | 自由文本 | 心情图标网格（5-7 位，卡片选择器变体） | 结构化输入才有筛选/统计价值；仍存字符串不动契约 |
| Day 切换 | 横滚变色胶囊 | 滑动指示器胶囊（TabBar 同款弹性位移） | 修复裁切，手感与 TabBar 统一 |
| 时间选择 | 双列点选列表 | 滚筒 + 5 分钟步进 + 常用时间快捷 chip | 点选 0-59 分钟是全局最重交互 |
| 主题选择 | 三卡变色 | 卡片选择器 + 按压回弹 | 已是正确形态，补动效即可 |
| 账本占比/趋势 | 两张卡平铺 | 分段控件切换单卡 | 省纵向空间，即时生效语义吻合（P2 可选） |
| 删除确认 | 居中确认框 | 保持现状 | 破坏型操作需要阻断感，不适合 Q 弹化 |

## 兼容性核对

- Q 弹只动 transform；haptic 仅限"确认时刻"，chip 选中属合规边界内（与打卡同级）。✅
- 滚筒自绘，不引 `@react-native-picker` 类新原生依赖。✅
- 所有选中态颜色走 token，浅色主题选中对比度 ≥4.5:1 自检。✅
