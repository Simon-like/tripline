# 对比报告 · 背景装饰与空状态（C 类）

> 2026-09-17。项目目前"白得单调"：全 App 唯一装饰是首页 CardScene 山景 SVG；空状态清一色"图标 + 两行字"；总结/分享等仪式感页面纯白。本报告对比背景手法与空状态方案。

## 1. 背景手法对比

| 手法 | 观感 | 成本 | 双主题负担 | 适用位置 | 结论 |
|---|---|---|---|---|---|
| 纯白/极浅纯色（现状） | 干净但单薄、无记忆点 | 零 | 零 | — | 保留为列表页基底，但微调为带倾向的米白/深炭（C1） |
| tonal 色阶分层（M3 surface container 思路） | 层级靠明度而非分割线，现代干净 | 低：调 token | 成对调整 | 全部列表页 | ✅ 主选 |
| 局部渐变点缀（hero/卡片头图） | 仪式感强但不吵 | 低-中：Skia LinearGradient | 渐变色进 token | 总结封面、预算英雄卡、旅程卡头图 | ✅ 仪式位专用 |
| mesh gradient + 5% 噪点 | 胶片质感、消除数码塑料感 | 中：Skia + 一张 tileable 噪点 PNG | 噪点 tile 通用，渐变双份 | 总结页、空状态插画底 | ✅ 总结页方案 B 采用 |
| 全屏渐变/全屏噪点 | 易脏、伤可读性 | — | — | 不用 | ❌ |
| 大号水印图形 | 低频页仪式感 | 低：SVG | token 配色 | 空状态、返程页头 | ○ 可选 |

**纪律**：列表页保持平色 + tonal 分层，把渐变"省"给仪式感时刻——与 Spotify/Notion/Linear 的 2025 主流一致。

## 2. 空状态对比

| 方案 | 内容 | 成本 | 评价 |
|---|---|---|---|
| 现状：图标 + 两行字 | 72pt 图标 + 「还没有…」 | 已有 | 说了"是什么"，没说"为什么/怎么办"，无个性 |
| 三要素版（推荐） | 场景 SVG 插画（CardScene 风格扩展一组：空行李箱/空白地图/空账本/空相册）+ 一句场景文案 + 唯一主按钮 | 中：4-6 张手写 SVG | 手写 SVG 零资产成本、天然双主题、契合 Expressive Pop |
| 预览填充版（进阶） | 空态直接展示"填满后长什么样"的半透明示例卡 | 中 | 教育性最强，首页空旅程适用（示例旅程卡） |
| 第三方插画库 | 现成插画 PNG/Lottie | 高：资产 + 风格不统一风险 | ❌ 与手写 SVG 语言冲突 |

## 3. 空状态逐处落地建议

| 位置 | 现状 | 建议 |
|---|---|---|
| 首页无旅程 | 大紫块 + 山图标 | 示例旅程卡预览 + 「创建你的第一段旅程」单按钮 |
| 清单为空 | 白卡 + 图标 | 空行李箱插画 + 「用推荐模板填满它」次行动（模板能力已有） |
| 行程为空 | 白卡 + sun 图标 | 空白地图/路标插画 + 「给 Day 1 加第一笔安排」 |
| 手账为空/半空屏 | 下半屏全空 | 空相册插画 + 「30 秒记下此刻」；半空时底部补引导卡 |
| 账本图表单日/无数据 | 大片空白 + 一个孤点 | 数据 <3 天时折线图整体替换为占位插画 + 「再记两笔就有趋势了」 |
| 返程/总结无记录 | 0 值 + 说明 | 保持 AC-2 温馨说明，配插画 |

## 兼容性核对

- 渐变/噪点均 Skia 或静态 PNG tile，无新原生依赖。✅
- 所有新色值进 token（深浅成对），禁止散写。✅
- 空状态插画为手写内联 SVG，进 `packages/ui` 或组件目录，遵守 ADR 0002 风格（克制、可辨识）。✅
- 减弱动效：空状态入场级联取消，直接呈现。✅
