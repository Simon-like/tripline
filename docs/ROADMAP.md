## 上半部 · 五波施工图景

| Wave | 目标 | 包含模块 | 出口标准（Exit Criteria） |
|---|---|---|---|
| **Wave 0** 工程基座 | 让所有模块有地可站 | M00 | 新机器克隆后按文档命令完成安装；iOS 与 Android dev build 均展示含五个 Tab 的空壳首页；packages/shared 五实体 schema 第一版冻结；SQLite+MMKV 可读写；导出码编解码往返一致 |
| **Wave 1** 核心闭环 | "行前+行中"最小可用 | M01–M04 | 双端 dev build 可完整走通：创建旅程 → 清单勾选到 100%（有彩带）→ 行程三态打卡 → 记一笔并看到预算/占比/趋势联动 |
| **Wave 2** 情感闭环 | "行后"记录与分享 | M05–M08 | 走通：手账记录（相册选图）→ 返程检查 → 自动生成总结并复制 → 导出码分享、另一台设备粘贴导入后数据等价 |
| **Wave 3** 体验增强 | 逐个评审、逐个增强 | M09–M12 | 每个模块独立走完全生命周期并验收；任一模块延期不阻塞其他模块 |
| **Wave 4** 上云与智能化 | V2 范围，需后端/前置调研 | M13–M17 | M13 完成多端同步一致后，其余模块逐个立项评审 |

当前所在波次：**Wave 1 基础版已验收，Wave 2 收尾整改**。M05 照片扩展与 M08 已实现但待补验收，M07 基础总结已实现待验收，不能认定情感闭环已完成。AI 与服务端工作按 Simon 本次要求留到下一迭代。详见 [基础收尾审阅](reviews/2026-09-15-foundation-closeout-review.md)。
