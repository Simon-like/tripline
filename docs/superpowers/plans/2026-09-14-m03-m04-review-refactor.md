# M03/M04 独立审阅与修整计划

目标：对照模块验收标准审阅行程与账本，修复确定的数据与交互缺陷，保持既有实体 schema 和原生依赖不变，并给出可直接照做的设备启动与打包步骤。

1. 核对 M03/M04 需求、技术方案、共享契约、SQLite/Web 双实现及现有测试，记录产品取舍与未决点。
2. 修复可复现的 P1 问题：分类占比舍入、预算警告阈值、Web 删除旅程的子记录级联、表单错误在弹层中不可见。对关键纯逻辑补边界测试。
3. 复核页面结构与图标系统，消除有维护成本的重复实现或文档偏差，但不扩大冻结契约和原生依赖范围。
4. 运行 lint/typecheck/test，并尽可能在现有模拟器验证页面与原生构建；记录未验证项，不擅自宣称正式验收通过。
5. 更新审阅记录、README/设备速查、PROGRESS 与 ROADMAP，提供极简点击路径及开发包/分发包说明。

完成标准：主分支可安装可启动；明确修复项、检查证据、剩余产品决策与设备验收界限。
