> 本文档是整个项目的**活文档**：产品定位、设计 token、术语等全局事实只在这里写全，其他文档一律链接引用。**任何影响全局的事实变化时，必须同步更新本文档**（更新时机见文末）。

## 产品定位

> **从收拾行李，到安全回家**——一个以「时间轴 + 旅程状态」为主轴的旅行全流程管理+记录工具。

- 不做社区、不做交易，专注"管理 + 记录"这一件事。
- 核心差异化：所有功能挂在**旅程状态**上，用户随时知道自己处于哪一步、下一步该做什么。
- 设计诉求（Simon）：无复杂配置、轻松易上手；界面近现代；动画体验非常解压；架构可持续拓展。

## 目标用户

20-35 岁、每年 2-5 次旅行的年轻人群：情侣出游、朋友结伴、自由行爱好者。出行前焦虑怕漏带；旅途中想记账但嫌专业记账软件太重；旅行结束想留点东西但懒得整理。

## 信息架构

```
首页（旅程列表 + 导入口 + 创建）
 └── 旅程详情（顶部状态标签 + 导出入口）
      ├── 🧳 清单（行前清单 + 智能提醒）
      ├── 🗺️ 行程（每日时间轴）
      ├── 💰 账本（预算 + 占比图 + 趋势图 + 流水）
      ├── 📔 手账（记录此刻 + 见闻流）
      └── ✈️ 返程（检查清单 + 总结 + 导出）
```

## 设计方向 B「弹跳气泡」Expressive Pop · 完整 token 表

**一句话风格**：Material 3 Expressive 基因 + Duolingo 式多巴胺——高饱和色彩、超大字体、万物皆可弹。

**图标系统**：应用内所有图标位统一使用内联 SVG（`packages/ui` 的 `Icon` 组件，基于 react-native-svg，24×24 viewBox、stroke≈2、round cap/join、`size`/`color` 由调用方传入）；**禁止把 Emoji 当图标用**（iOS 26 Emoji 字体级联回归，RN #56183 / xcodes #468），决策详见 [ADR 0002](adr/0002-icon-system-svg.md)。用户内容中的 Emoji 不受影响。

### 字体

| 用途 | 字体栈 | 字重 |
|---|---|---|
| 中文 | MiSans → HarmonyOS Sans SC → PingFang SC | Semibold–Bold |
| 英文/数字 | Plus Jakarta Sans 或 Satoshi | Bold / ExtraBold |

规则：全篇无衬线、超粗字重建立层级；大数字标题可用可变字重做 weight 动画；含中文必须显式中文字体栈；**中文禁用斜体**；所有文本显式 `lineHeight`。

### 动效参数

| 项 | 约定 |
|---|---|
| 弹簧物理 | Reanimated 4 只指定 `duration` + `dampingRatio`（行为可预测，契合 M3 Expressive）；参考手感 stiffness≈300 / damping≈20 的轻过冲效果 |
| 即时反馈 | 100–150ms |
| 常规过渡 | 200–350ms |
| 展开/收起 | 300–400ms |
| 庆祝类 | 上限 600ms–1.2s |
| 级联入场 | 列表/卡片 40ms 间隔 stagger 弹入；超过 10 项降级为瞬时变色 |
| 勾选 | 圆点 morph 成对勾 + 粒子迸发（Skia 手写） |
| 打卡/记账成功 | 600ms 彩带庆祝 |
| 数字变化 | 滚动计数（odometer） |
| Tab 切换 | 图标形状变形（圆形↔圆角方）+ 指示器弹性滑动 |
| 长按编辑 | 行程卡片抖动编辑态（iOS 式 jiggle） |
| 触感 | 仅"确认时刻"（勾选/打卡/盖章）配一次轻 haptic |

12 条动效原则全文见调研底稿 [03-设计与动效趋势](../deliverables/research/03-设计与动效趋势.md)「三、动效原则清单」，施工时逐条遵守；性能红线：只动画 `transform`/`opacity`，尊重系统减弱动效设置。

### 组件质感

- 胶囊按钮：圆角 999px
- Bento 卡片：大圆角 24px，首页大小不一拼贴
- FAB：彩色填充
- Tab 栏：左右留边的悬浮圆角药丸形；iOS 原生模糊、Android/Web 半透明回退，弹性滑动选中态（细节见 [ADR 0003](adr/0003-floating-glass-navigation.md)）
- 超大号标题 32–40px + 圆角胶囊标签；行程时间轴节点为大号彩色圆球

## 核心交互清单（已在 Demo 中验证，来自产品简报）

1. 清单勾选联动打包进度条（"还差 N 项"）
2. 行程条目三态打卡：计划 → ✓ 已去 → 已取消
3. 记一笔联动预算（剩余金额、已用百分比、超支警告）
4. 消费可视化：分类占比（扇形/占比条 + 图例）、每日趋势（折线）
5. 手账：文字 + 相册选图 + 标签（推荐/避雷/美食…），自动时间戳；照片只存本机
6. 返程检查清单：行李清点、退房检查、发票、到家待办
7. 旅行总结自动汇总：完成行程数、总花费对预算、见闻数、照片数；一键复制分享
8. 行程共享「导出码」：旅程数据编码进带关键词的分享文案，粘贴整段文案自动识别导入；无需服务器

## 术语表（全局统一用词）

| 术语 | 定义 |
|---|---|
| 旅程（Journey） | 产品的第一公民，一次旅行的全部数据容器 |
| 旅程状态 | ⏳ 准备中 → 📍 游玩中 → ✨ 已结束，基于当前日期与起止日期自动识别 |
| 三态打卡 | 行程条目的状态循环：计划 → ✓ 已去 → 已取消 |
| 导出码 | `{schemaVersion, payload, checksum}` 编码串，嵌入分享文案；无需服务器、长期有效、粘贴整段文案自动识别导入 |
| 软删除 | 行记录带 `deletedAt` 时间戳（tombstone），不物理删除，为云同步预留 |
| schemaVersion | 数据模型版本号，本地 schema 与导出码均携带，驱动迁移与 upcaster |
| dev build | Expo development build，本项目开发基线（非 Expo Go） |
| 评审门 | 模块生命周期中的 approve/reject 检查点，唯一批准人是 Simon |
| 契约冻结 | `packages/shared` 接口经技术评审批准后锁定，变更需重新评审 |
