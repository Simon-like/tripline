# 「旅迹 TripLine」设计调研综述与三大原型方向

## 一、调研要点速览

**1. 2025–2026 移动 UI 大趋势。** Google 在 I/O 2025 发布 Material 3 Expressive（随 Android 16 / Wear OS 6 落地），核心特征是：弹簧物理动画（springy motion）、形状变形（shape morphing，如按钮按下时相邻元素自然让位）、更鲜明的动态色彩、加粗强调的排版层级，以及动效与触感（haptic）的配对。Bento 网格仍是模块化信息组织的主流；玻璃拟态进化为更克制的 Glassmorphism 2.0 / Liquid Glass（仅用于浮层、导航、模态，以模糊表达"临时层级"）；超大字号排版（oversized typography）成为建立层级的首选手段，衬线体（serif）正在复兴。

**2. "解压"交互标杆。** Flighty（2023 Apple Design Award 得主）证明旅行类 App 可以靠极致打磨的动效和"无聊般顺滑"的可靠性取胜，其动态岛进度环、飞行中进度条都是标杆。Duolingo 用 Rive 运行时动画做奖励反馈（宝箱抖动、宝石迸出），动画+触感配对被评价为"近乎成瘾"。Linear 的命令栏、Raycast 启动器、Arc 标签页动画均使用带轻微过冲（overshoot）的弹簧曲线，被视为"新产品的默认质感"，而纯 cubic-bezier 已显得"老气"。

**3. 旅行 App 竞品格局。** Wanderlog 以"地图优先+多彩易用"的视觉化行程规划被评为界面最佳；TripIt 界面陈旧但自动化强；Polarsteps 以 GPS 自动生成"美丽旅行日志+足迹地图"打动用户；Stippl 融合规划+账本+日志——与 TripLine 的产品形态最接近。市场空白：**没有一款同时做到"高颜值动效 + 全旅程闭环"**，这是 TripLine 的机会。

**4. 色彩与字体趋势。** 旅行/生活方式品类的 2025 主流：赤陶/焦赭大地色（saturated earth tones）、暖中性色（砂岩米、暖灰、奶油白）、日落珊瑚与暖棕、深沉情绪色（深海军蓝、森林绿）用于暗色底；字体上"编辑风衬线标题 + 高可读无衬线正文"的配对正在回归。

## 二、三大原型设计方向

### 方向 A：「纸上旅途」Warm Paper Journal（暖纸手账风）

**一句话风格：** 像一本会呼吸的旅行手账——奶油纸面、手写温度、翻页与贴纸式的轻快乐趣。

- **配色：** 背景 `#FBF6EE`（奶油纸）/ 卡片 `#FFFFFF` / 主色 `#C96F4A`（赤陶橘）/ 强调色 `#E8A87C`（杏色）+ `#7D9B76`（苔绿，用于完成态）/ 正文文字 `#3A322B` / 次要文字 `#9A8F83` / 分隔线 `#EDE3D5`
- **字体策略：** 中文标题用「思源宋体 Noto Serif SC / 霞鹜文楷」营造手账感，正文「思源黑体 Noto Sans SC / PingFang SC」；英文标题衬线用 `Cormorant Garamond` 或 `Lora`，正文 `Inter`。数字账本栏用等宽 `JetBrains Mono / 等宽数字 tabular-nums`。
- **布局特征：** 单栏纵向流 + 大留白；清单项为"纸条"卡片（微倾斜 ±0.5°、纸胶带装饰角）；行程时间轴为左侧手绘风竖线 + 圆点邮戳；游记页采用杂志式首字放大与图片贴纸布局。
- **标志性动效：** 勾选清单时——对勾以手绘笔触一笔画出（stroke-dashoffset 动画 300ms），纸条卡片轻微回弹并飘落一枚"印章"图标；全部打包完成时整页飘落纸屑彩带（confetti，1.2s）；页面切换为"翻页式"横向 shared-element 过渡；下拉刷新是一枚纸飞机被拉下后松手飞走。
- **组件质感：** 圆角 14–18px 纸感卡片 + 极淡投影（0 2 8 rgba(58,50,43,.06)）；按钮为"印章盖章"形态（按下时缩放 0.96 + 印记色加深）；Tab 栏为米白底 + 顶部细缝线纹理。

### 方向 B：「弹跳气泡」Expressive Pop（大胆现代表现力风）

**一句话风格：** Material 3 Expressive 基因 + Duolingo 式多巴胺——高饱和色彩、超大字体、万物皆可弹。

- **配色：** 背景 `#F4F2FB`（淡紫白）/ 主色 `#5B4FE9`（电紫罗兰）/ 强调色 `#FF6B4A`（日落橙）+ `#FFC93C`（明黄，庆祝专用）+ `#22C55E`（完成绿）/ 文字 `#17132B` / 次要 `#6E6A85`
- **字体策略：** 全篇无衬线、超粗字重建立层级：中文「MiSans / HarmonyOS Sans SC / PingFang SC」Semibold–Bold；英文 `Plus Jakarta Sans` 或 `Satoshi` Bold/ExtraBold；大数字标题用可变字重字体做 weight 动画。
- **布局特征：** Bento 网格首页（行程卡、天气卡、倒计时卡、账本摘要卡拼贴，大小不一）；超大号标题（32–40px）+ 圆角胶囊标签；行程时间轴节点为大号彩色圆球。
- **标志性动效：** 全面弹簧物理（stiffness≈300, damping≈20，带轻过冲）；勾选清单时圆点 morph 成对勾并伴随粒子迸发；长按行程卡片进入抖动编辑态（iOS 式 jiggle）；打卡/记账成功触发 600ms 全屏庆祝（彩带+弹跳图标）；Tab 切换时图标做形状变形（圆形↔圆角方）且指示器弹性滑动；卡片进入列表时 40ms 间隔级联（stagger）弹入。
- **组件质感：** 胶囊按钮（圆角 999px）、大圆角 24px bento 卡、彩色填充 FAB；Tab 栏为悬浮圆角药丸形（毛玻璃底 + 彩色激活态）。

### 方向 C：「夜航地图」Dark Atlas（暗夜沉浸地图风）

**一句话风格：** Flighty 式的暗夜驾驶舱——深海军蓝底、发光航线、数据仪表盘般的精准与冷静解压。

- **配色：** 背景 `#0D1526`（深海军蓝）/ 卡片 `#16203A` / 主色 `#4EA8FF`（航迹蓝）/ 强调色 `#FFB454`（琥珀橙，CTA 与倒计时）+ `#3DDC97`（薄荷绿，完成态）/ 文字 `#EEF2FA` / 次要 `#8A96B0` / 地图描线 `#24335A`
- **字体策略：** 中文「思源黑体 Noto Sans SC / PingFang SC」Regular–Medium（避免粗黑在暗底糊边）；英文 `Space Grotesk`（标题，带科技感）+ `Inter`（正文）；所有数字用 `tabular-nums`，大数字读数可用等宽字体呼应航空感。
- **布局特征：** 地图优先——首页下半部为迷你暗色地图（航线以发光描线呈现），上半部为航班/行程"仪表卡"；行程时间轴为垂直航线图（节点=机场代码徽章）；账本页为仪表盘式环形图+大数字。
- **标志性动效：** 航线以 1.5s stroke 绘制动画逐段点亮（类似 Flighty 飞行进度）；打卡时节点徽章做"雷达脉冲"涟漪扩散；页面切换用地图缩放式 zoom 过渡（从地图上的点放大进入详情）；记账成功时数字滚动计数（odometer 300ms）+ 环形图弹性填充；下拉刷新为"雷达扫描"旋转扫过。
- **组件质感：** 圆角 16px 深色卡 + 1px 半透明描边 `rgba(78,168,255,.15)` + 内发光；按钮为琥珀色实底或蓝边幽灵按钮；Tab 栏为暗色毛玻璃（blur 20px）+ 发光激活指示线。

**三者区分度：** A 是"情感记录优先"（适合游记/清单为 hero），B 是"效率与乐趣优先"（适合清单/账本的密集交互），C 是"行程掌控优先"（适合时间轴/地图为 hero）。三者共享同一套信息架构，仅换皮肤与动效语言，完全满足"可持续拓展"。

## 三、动效原则清单（可执行）

1. **弹簧优先：** 所有用户触发的微交互用弹簧物理（带过冲），不用线性/纯 ease 曲线；入场轻过冲、出场干净收束。
2. **时长预算：** 即时反馈 100–150ms，常规过渡 200–350ms，展开/收起 300–400ms，庆祝类上限 600ms–1.2s，超过即显拖沓。
3. **进入 ease-out / 离开 ease-in：** 元素进场先快后慢，离场先慢后快；位移 8–16px + 透明度即可，不做大距离飞行。
4. **动效即语义：** 上滑=出现、下滑=关闭、缩放=层级进入；全产品统一一套运动语言，同一动作永远同一种动效。
5. **动效+触感配对：** 勾选、切换、盖章、打卡等"确认时刻"配一次轻 haptic；仅关键确认用震动，常规点击不配，避免轰炸。
6. **级联入场（stagger）：** 列表/卡片以 30–50ms 间隔错峰入场，制造"多米诺"解压感；超过 10 项的批量操作降级为瞬时变色，不做逐个弹跳。
7. **动画不阻塞输入：** 过渡中界面保持可交互；任何动画可被新手势打断并平滑接管（手势驱动优先于定时播放）。
8. **进度庆祝分级：** 单项完成=对勾描绘+轻弹跳；整清单完成=印章/彩带；整趟旅程完结=全屏庆祝 + 可分享成就卡。强度匹配重要性。
9. **骨架屏→内容变形：** 加载用骨架屏，内容到达时骨架块 morph 成真实卡片（shape morphing），不用生硬替换或转圈。
10. **创意下拉刷新：** 下拉手势绑定角色化动画（纸飞机/雷达/气球），松手时回弹执行——这是成本最低的记忆点。
11. **性能红线：** 只动画 `transform` 与 `opacity`（GPU 合成层）；禁用宽高/边距动画；中端安卓实机测 60fps；复杂庆祝动画用 Lottie/Rive 资产而非手写 DOM。
12. **尊重减弱动效：** 实现 `prefers-reduced-motion`：不是把时长归零，而是把位移/弹跳换成瞬时但可见的状态跳变，保留反馈信号。
