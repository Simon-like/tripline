# 旅迹 TripLine · 产品简报（供设计与原型使用）

## 定位

> **从收拾行李，到安全回家** —— 一个以「时间轴 + 旅程状态」为主轴的旅行全流程管理+记录工具。

- 不做社区、不做交易，专注"管理 + 记录"这一件事。
- 核心差异化：所有功能挂在"旅程状态"上（⏳ 准备中 → 📍 游玩中 → ✨ 已结束），用户随时知道自己处于哪一步、下一步该做什么。
- 设计诉求（来自产品负责人 Simon）：无复杂配置、轻松易上手；界面近现代；动画效果体验非常解压；架构可持续拓展。

## 目标用户

20-35 岁、每年 2-5 次旅行的年轻人群：情侣出游、朋友结伴、自由行爱好者。出行前焦虑怕漏带；旅途中想记账但嫌专业记账软件太重；旅行结束想留点东西但懒得整理。

## 信息架构

```
首页（旅程列表 + 导入口 + 创建）
 └── 旅程详情（顶部状态标签 + 导出入口）
      ├── 🧳 清单（行前清单 + 智能提醒）
      ├── 🗺️ 行程（每日时间轴）
      ├── 💰 账本（预算 + 占比图 + 趋势图 + 流水）
      ├── 📔 手账（记录此刻 + 见闻流）
      └── ✈️ 返程（检查清单 + 总结 + 导出）
```

## 核心交互（已在 Demo 中验证）

1. 清单勾选联动打包进度条（"还差 N 项"）
2. 行程条目三态打卡：计划 → ✓ 已去 → 已取消
3. 记一笔联动预算（剩余金额、已用百分比、超支警告）
4. 消费可视化：分类占比（扇形/占比条 + 图例）、每日趋势（折线）
5. 手账：文字 + 相册选图 + 标签（推荐/避雷/美食…），自动时间戳；照片只存本机
6. 返程检查清单：行李清点、退房检查、发票、到家待办
7. 旅行总结自动汇总：完成行程数、总花费对预算、见闻数、照片数；一键复制分享
8. 行程共享「导出码」：旅程数据编码进带关键词的分享文案，粘贴整段文案自动识别导入；无需服务器

## 演示数据（原型统一使用）

- 旅程：**「香格里拉 · 5天4晚」**，10月2日出发—10月6日返程，总预算 ¥4,500，同行人：阿 May
- 状态：⏳ 准备中（出发前 12 天）
- 清单分类：证件/交通/住宿/电子/药品/衣物/财务（示例条目：身份证、充电宝、防晒霜、氧气瓶预订…）
- 行程示例（Day 1）：09:30 飞昆明转机 / 14:00 抵达香格里拉 / 16:00 独克宗古城 / 19:00 藏餐·牦牛火锅
- 账本示例：已花 ¥1,280（机票预付 860、客栈定金 300、氧气瓶 120），分类：交通/住宿/餐饮/门票/购物/其他
- 手账示例：「转经筒下许了个愿 ✨」标签 #推荐，带 2 张图
- 返程清单：充电器、房卡退还、发票收好、洗衣服、导照片

## 设计硬规则（所有原型必须遵守）

1. 页面含中文时字体栈必须显式包含中文字体（如 `PingFang SC`、`Noto Sans SC`、`MiSans`），禁止用纯拉丁展示字体渲染中文标题。
2. 中文禁用斜体（`font-style: italic`）。
3. 图标优先内联 SVG 或 Emoji，不用 Font Awesome 彩色圆角方块。
4. 图片用代码绘制（SVG/CSS 渐变占位）或可靠外链；禁止空白图区。
5. 单文件 HTML（内联 CSS/JS），可直接双击打开；Google Fonts 需带系统字体兜底。
6. 主内容首屏立即可见，不做登录墙、不做滚动触发才显现的内容。
